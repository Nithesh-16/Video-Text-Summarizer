# Video-Text-Summarizer

A Streamlit application that helps transcribe and summarize video/audio content. This tool can:
- Transcribe YouTube videos
- Convert audio files to text
- Generate summaries of the transcribed content
- Provide interactive chat functionality with the transcribed content

## Features
- YouTube video transcription
- Audio file transcription
- Text summarization
- Interactive chat interface
- User-friendly UI

## Requirements
- Python 3.x
- Streamlit
- Other dependencies listed in requirements.txt
